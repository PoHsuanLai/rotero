Rotero is a local-first reference manager. Your library is a SQLite database and
a folder of PDFs on your own machine — there is no account, no sync service you
have to trust, and nothing phones home.

This guide covers the desktop app and the three things that connect to it: the
browser extension, the Word add-in, and the MCP server.

## Start here

If you have just installed Rotero, read [Install]({base}/docs/install) and
[First steps]({base}/docs/first-steps) in order. Together they take about ten
minutes and get you from a downloaded file to an annotated paper.

If you are migrating from Zotero, start with
[BibTeX and other formats]({base}/docs/bibtex) — Rotero imports `.bib`, `.ris`,
`.nbib`, and CSL-JSON, and can keep a `.bib` file continuously in sync for LaTeX.

## Finding things

The sidebar on the left groups pages by what you are trying to do. Search covers
every page, and matches inside code blocks and tables as well as prose.

Keyboard shortcuts are written in macOS notation — `⌘` means Ctrl on Windows and
Linux, and the app accepts either.
